# Papers for the 15-crystal list

**None of the 15 crystals has been made or measured.** They come from the GNoME database
(paper 01). Six also have Materials Project entries, which were copied from GNoME: #2, #3, #4, #5, #10
and #12. A web search for the exact formulas (2026-10-06, and step 90 before it) found no paper on
any of them. The papers below cover their **parent families**.

The PDFs are not in git, because the repo is public. Only this list is committed.
